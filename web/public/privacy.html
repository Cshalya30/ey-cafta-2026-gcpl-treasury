Privacy notice

GCPL Treasury Command · last reviewed 18 October 2026

In one line: this application collects no personal data, sets no cookies, loads no third-party script, and sends nothing anywhere. It runs entirely on the machine it is installed on.

What this application is

GCPL Treasury Command is a demonstration built for the EY CAFTA 2026 case championship. It models the treasury operating model of an invented company, Global Consumer Products Ltd, using synthetic data generated by a seeded script in this repository. It is not connected to any bank, any payment rail or any live financial system, and it never moves money.

What is stored, and where

ItemWhere it livesWhy
Acting persona and display currency Your browser's local storage, on this device only So the console reopens as you left it. Written only if you accept the on-screen notice.
Filters, selected entity, active lens and tab The page URL So any view can be copied and pasted to a colleague. Nothing is persisted.
Synthetic treasury data data/gcpl.db, a local SQLite file The demonstration dataset. Generated, not collected.
Audit events The same local file Records actions taken inside the demo, attributed to a persona, not to a person.

What is not stored

  • No cookies of any kind, first-party or third-party.
  • No analytics, telemetry, tag manager, pixel, session recorder or advertising script.
  • No real names, email addresses, IP-address logs or device fingerprints.
  • No real bank account numbers. Accounts carry four digits and nothing more; a test in the suite fails the build if a longer number ever reaches the database.
  • No API keys or credentials, because the application integrates with nothing.

People named in the data

Every person named in this application is invented, including the ten persona holders. Any resemblance to a real individual is coincidental. The one real identifier is the author of the repository, recorded in the commit history.

Bank names

Bank names in the dataset are real, because bank panels and country coverage are public information. No invented financial figure is attached to any real bank as its own position: banks appear as counterparties to an invented company's invented accounts.

Declining storage

Declining the on-screen notice is a real choice, not a dismissal. The storage adapter refuses to write, and your persona and currency choices reset when you reload. Every other part of the application behaves identically.

Clearing what is stored

Clear site data in your browser, or delete data/gcpl.db and regenerate it. Regenerating with the same seed reproduces the file exactly.
